# Security policy

Beads for Laravel is a local development tool: its routes only exist when the app runs in the
`local` environment. Even so, if you find a security issue, please report it privately.

**Do not open a public issue.** Use [GitHub's private vulnerability reporting](https://github.com/codeberrynl/beads-for-laravel/security/advisories/new)
for this repository. You will get a reply within a few working days. We fix confirmed issues in the
latest release and credit you in the release notes, unless you prefer otherwise.
